# Naowee · Demos Hub

Catálogo vivo de las demos y módulos refinados de Naowee para el SUID / Ministerio del Deporte.

**En vivo:** https://naowee-tech.github.io/naowee-demos-hub/

Cada card enlaza a la demo en GitHub Pages y a su repositorio, con versión (tag o footer del módulo) y notas de alcance. La data vive en el array `DEMOS` dentro de `index.html` — para agregar o actualizar una demo, edita esa entrada y haz push.

Mantenido por Doug Vargas (@douguizard).
